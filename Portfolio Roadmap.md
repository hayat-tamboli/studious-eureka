## 8. Validate the content and experience

- [ ] Proofread every page and project
- [ ] Test every navigation link, external link, form, and download
- [ ] Review the portfolio as each target audience
- [ ] Check that the strongest work and call to action are easy to find
- [ ] Ask for feedback from a few trusted reviewers
- [ ] Resolve high-impact usability, content, and visual issues
- [ ] Confirm that project claims and metrics are accurate

## 9. Launch and measure

- [ ] Configure the production domain
- [ ] Set up hosting, deployment, and environment variables
- [ ] Configure analytics or privacy-friendly measurement if needed

- [ ] Run a final production smoke test
- [ ] Publish the site
- [ ] Confirm that search previews, social previews, and downloads work correctly
- [ ] Record the launch date and initial baseline metrics

## 10. Maintain and improve

- [ ] Schedule regular content and résumé reviews
- [ ] Add, archive, or refresh projects as experience grows
- [ ] Monitor uptime, forms, analytics, and broken links
- [ ] Keep dependencies and security settings updated
- [ ] Review performance and accessibility periodically
- [ ] Capture feedback and maintain a prioritized improvement backlog
